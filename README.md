# ECE1779 — Cloud Inventory Manager

A cloud-based inventory management system developed as a group project for **ECE1779: Cloud Computing** at the University of Toronto.

## Project Overview

The goal is to build a scalable inventory management application that supports product management, stock tracking, and real-time inventory updates.

## Planned Tech Stack

- **Frontend:** React
- **Backend:** Node.js / Express
- **Database:** PostgreSQL
- **Containerization:** Docker / Docker Compose
- **Cloud Deployment:** DigitalOcean / Docker Swarm
- **Real-time Communication:** Socket.IO / Redis
- **CI/CD:** GitHub Actions
